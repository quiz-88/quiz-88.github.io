What is quiz-88?

quiz-88 is a browser arena — a grid of games you enter directly, no install layer between you and the session. Every tile links to a live game, and the search bar filters the grid in real time as you type.

How the grid is laid out

There's no deep menu system here. Racing sits next to puzzle, shooters sit next to clickers, and the grid is built to be scanned fast rather than browsed slowly. If you already know a title's name, search will get you there quicker than clicking around.

Running without a client

Every session on quiz-88 executes inside the tab itself. That keeps things fast on shared or locked-down machines — nothing to install, nothing left behind when the tab closes. Performance still depends on your own device and connection.

Got a title to add?

The grid expands over time. Send a suggestion through the Contact page if there's a browser game you want to see added.
